# Schriftlizenzen

Alle drei Familien stehen unter der **SIL Open Font License 1.1**. Die erlaubt
das Mitliefern mit einer Website ausdrücklich, auch gewerblich, solange die
Schriften nicht einzeln verkauft werden.

| Familie | Entwurf | Bezug |
|---|---|---|
| Archivo | Omnibus-Type | fonts.google.com/specimen/Archivo |
| Bodoni Moda | Indestructible Type | fonts.google.com/specimen/Bodoni+Moda |
| IBM Plex Mono | IBM / Mike Abbink, Bold Monday | fonts.google.com/specimen/IBM+Plex+Mono |

Die Dateien wurden am 13.09.2026 von `fonts.gstatic.com` geholt, auf den Satz
`latin` beschränkt und liegen als woff2 daneben. Der vollständige Lizenztext
steht bei jeder Familie unter der oben genannten Adresse.
