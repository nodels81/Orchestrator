# PATCH-01-artwork.svg — Wortmarke BELLOWERK / Manufaktur

Entwurf vom 15. September 2026, nachgebaut nach dem bestehenden Logo auf
`marke/instagram-logo.jpg`: gesperrte geometrische Versalien über einer Schreibschrift, die unter der
rechten Hälfte sitzt. Der Name ist neu, das Layout ist das alte.

**Schrift ist in Pfade gewandelt** — die Datei enthält kein `<text>`-Element, nur Konturen. Damit
kann jede Gravur-Software sie verarbeiten, ohne dass eine Schrift mitgeliefert werden muss.

| | |
|---|---|
| Versalien | Josefin Sans SemiBold, Sperrung +20 % |
| Schreibschrift | Allura |
| Lizenz | beide SIL Open Font License — kommerzielle Nutzung und Umwandlung in Pfade erlaubt |
| Farbe | einfarbig `#211C15`; für die Gravur ist nur die Form relevant |

## Was noch zu klären ist

1. **Ist das die Schrift?** Das Original wurde nicht mit diesen Fonts gesetzt — es ist eine
   Annäherung aus dem Foto. Wer immer das alte Logo gebaut hat, hat vermutlich eine offene
   Vektordatei. Die wäre besser: Kerning und Schwung der Schreibschrift stimmen dann exakt.
2. **Proportion Versalien zu Schreibschrift** und wie weit die zweite Zeile nach rechts rutscht —
   auf dem Patch mit 110 × 18 mm entscheidet das über den Gesamteindruck.
3. **Rundes Signet:** Auf dem Instagram-Profilbild sitzt die Marke in einem Kreis. Falls das auf
   Anhänger oder Aufkleber soll, ist das eine eigene Datei; sag Bescheid, dann baue ich sie.
