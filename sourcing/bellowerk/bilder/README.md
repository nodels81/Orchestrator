# Beispielbilder für Lieferanten

Instagram und die Website waren aus dieser Umgebung nicht erreichbar. Björn legt die Fotos hier ab;
der Einkäufer hängt an jede Anfrage **1–2 Bilder** an: immer die bemaßte Zeichnung aus
`../zeichnungen/` plus ein Foto aus diesem Ordner.

## Regeln

- Tageslicht, neutraler Hintergrund, Lineal oder Maßband im Bild bei Detailfotos.
- Max. 2 MB pro Bild (Alibaba-Chat, WeChat), JPG.
- Pfeile/Maße direkt ins Bild schreiben, wenn etwas erklärt werden muss (z. B. "25 mm", "no stitching").
- Keine Kundenfotos mit Gesichtern.
