# Pfad `sourcing/autopflege/`

Zweiter, eigenständiger Sourcing-Pfad: **Delatec — Autopflege-Eigenmarke für Lackiererei und
Autowerkstatt**.
Getrennt von Bellowerk — andere Marke, andere Lieferanten, anderer Tracker. Gemeinsam genutzt
werden nur die neutralen Nachrichtenvorlagen in `sourcing/vorlagen/` (Betreffzeilen und
Markennamen darin vor dem Senden ersetzen).

```
sortimentsbrief.md        Positionierung, Stufenplan, Sortiment, Ausschlüsse, offene Entscheidungen
zusatzverkauf.md          Anlass- und Thekenverkauf in der Werkstatt, Smart-Repair-Gimmicks
lieferanten/shortlist.md  Recherchierte Kandidaten China + Deutschland, mit Quellen
lieferanten/tracker.csv   Stand je Lieferant, nach jedem Kontakt fortschreiben
specs/                    Tech Packs je Artikel (entstehen nach der Sortimentsfreigabe)
```

Reihenfolge: `sortimentsbrief.md` ist die Wahrheit über das Sortiment. Erst wenn die dort offenen
Entscheidungen (Markenname, "Felgen oder Felgenreiniger", Zielkunde) geklärt sind, entstehen die
Tech Packs, dann gehen Anfragen raus.

Regel wie im Bellowerk-Pfad: Der Einkauf gibt kein Geld aus. Muster, Anzahlung, Bestellung und
jede Rezeptur-/Etikettenfreigabe gehen als nummerierte Entscheidung an den Inhaber.
