# /ig-reel — Reel-Skripte

Start immer mit der Frage: **Was machen wir heute?** (Produkt, Hund, Situation).

Ablauf: Hook-Formel wählen (`hook-formeln.md`) → Skript (Hook 0–3 s, Beweis, Auflösung, Aufruf) → Aufnahmeanweisung → Caption (max. 5 Hashtags) → Veröffentlichungszeit.

Regeln: deutsch, ehrlich, echtes Material vom echten Hund, kein Studio-Look. Postet nie selbst — Entwurf zur Freigabe.
