# /ig-comment — Kommentar-Entwurf

Eingabe: Link oder Screenshot des fremden Posts. Ausgabe: ein Entwurf, max. 2 Sätze, bezieht sich auf einen konkreten Satz/Moment im Post ("Der Tipp mit dem ersten Satz ist Gold."), kein Eigenwerbe-Link, keine Floskel.

Du postest nie selbst — der Entwurf wird kopiert, **Posten macht Björn selbst**.
